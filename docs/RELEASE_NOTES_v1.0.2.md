# BFR - Batch File Renamer — Release Notes v1.0.2

Tài liệu ghi chú phát hành chuẩn bị nộp duyệt cập nhật trên **Microsoft Partner Center** cho bản **v1.0.2** (Package Version: `1.0.2.0`).

---

## What's New in this Version (English - en-US)

### Release highlights for v1.0.2:
- **Complete Windows 11 Fluent Design Makeover**:
  - Brand-new modern UI with integrated borderless Fluent Titlebar, Windows 11 Mica/Acrylic styling, rounded corners, and soft elevation depth.
  - Redesigned **Rule Cards** inspired by PowerToys and WinUI 3: instant **Toggle Switch** on/off, clean parameters summary, and organized action menu.
  - Modern **Segmented Control** for quick file filtering and status chips.
- **Enhanced Preview Table Experience**:
  - Added a **Select / Deselect All** tri-state checkbox directly in the table header, making batch selections effortless.
  - Added full **Column Header Sorting**: Click any column header (Original Name, New Name, Status, Folder) to sort your files instantly in ascending or descending order.
  - Status display upgraded with **Visual Pill Badges** (🟢 Will Change, ⚪ Unchanged, 🔴 Conflict/Error) and inline Diff highlights.
  - New **Context Menu**: Right-click any row in the preview table to quickly open the file, view it in Windows File Explorer, copy original/new names, or remove it from the list.
- **In-App Rating & Review**:
  - Enjoying BFR? You can now rate and review the app directly from within the application or via the Settings menu.
- **Performance & Polish**:
  - Real-time reactivity improvements when selecting and deselecting individual files.
  - Full synchronization and localization updates across Vietnamese, English, French, and Simplified Chinese.
  - Up-to-date packaging compliance with the latest Microsoft Store policies.

---

## Những điểm mới trong phiên bản này (Tiếng Việt - vi-VN)

### Điểm nổi bật trong bản v1.0.2:
- **Lột xác giao diện toàn diện chuẩn Windows 11 Fluent Design**:
  - Thiết kế mới hiện đại với thanh tiêu đề tràn viền tích hợp, hiệu ứng Mica/Acrylic mờ, góc bo tròn và bóng đổ mềm mại.
  - **Thẻ quy tắc phong cách PowerToys / WinUI 3**: Nút gạt **Toggle Switch** bật/tắt nhanh, tóm tắt tham số trực quan, menu thao tác gọn gàng.
  - Bộ điều khiển **Segmented Tab** hiện đại giúp lọc nhanh trạng thái tệp mượt mà.
- **Nâng cấp trải nghiệm bảng xem trước (Preview Table)**:
  - Thêm ô **Chọn / Bỏ chọn tất cả** (Checkbox 3 trạng thái) ngay trên tiêu đề cột giúp thao tác chọn hàng loạt cực kỳ nhanh chóng.
  - Bổ sung tính năng **Sắp xếp theo tiêu đề cột**: Nhấp chuột vào bất kỳ tiêu đề cột nào (Tên cũ, Tên mới, Trạng thái, Thư mục) để sắp xếp tăng/giảm dần ngay lập tức.
  - Trạng thái hiển thị bằng **Pill Badges màu sắc sinh động** (🟢 Sẽ đổi, ⚪ Không đổi, 🔴 Trùng/Lỗi) kèm tô sáng phần tên thay đổi (Diff).
  - Thêm **Menu chuột phải (Context Menu)** trên từng dòng: Nhấp chuột phải vào tệp để mở nhanh tệp, mở thư mục chứa trong File Explorer, sao chép tên cũ/mới hoặc xóa tệp khỏi danh sách.
- **Đánh giá ứng dụng trực tiếp (In-App Store Rating)**:
  - Giờ đây bạn có thể dễ dàng đánh giá và gửi nhận xét cho ứng dụng trực tiếp trên Microsoft Store từ menu Cài đặt hoặc thông qua gợi ý đánh giá sau khi hoàn tất đổi tên.
- **Hiệu năng & Tinh chỉnh**:
  - Phản hồi thời gian thực tức thì khi chọn/bỏ chọn từng tệp đơn lẻ.
  - Đồng bộ và hoàn thiện toàn bộ các chuỗi ngôn ngữ trên cả 4 thứ tiếng (Tiếng Việt, Tiếng Anh, Tiếng Pháp và Tiếng Trung Giản thể).
  - Tối ưu gói đóng gói MSIX theo quy chuẩn và chính sách mới nhất của Microsoft Store.
